# 🐶🐱 Animal Traits — Show and Tell

영어 유치원 재원생을 위한 **SL2 수준 Show & Tell 발표 자료**입니다. 할머니 댁에 실제로 사는 강아지와 고양이 사진으로 `animal traits`를 설명하고 Essential Question에 답합니다.

- **Presentation Topic:** Animal Traits
- **Essential Question:** What is a perfect pet like?
- **대상:** 한국 영유 6~7세, SL2
- **발표 시간:** 약 2~3분 / 9 슬라이드
- **핵심 답:** A perfect pet is friendly, gentle, healthy, and loved. It is a loving family friend.

## 구성

| 파일 | 용도 |
|---|---|
| [`index.html`](index.html) | 9장 HTML 프레젠테이션 |
| [`script.html`](script.html) | 영어 발표문, 한국어 해석, 동작 가이드, 예상 질문 |
| [`cards.html`](cards.html) | 인쇄용 큐 카드 9장과 한 장 요약표 |
| `images/` | 사용자가 제공한 가족 반려동물 사진의 발표용 사본 |

## 발표 흐름

| # | 내용 | 핵심 문장 |
|---|---|---|
| 1 | Title | What is a perfect pet like? |
| 2 | 할머니 댁 반려동물 | My grandma has one dog and one cat. |
| 3 | Trait 뜻 | A trait tells how an animal looks or acts. |
| 4 | 강아지의 생김새 | White fluffy fur, pointed ears, and a curly tail. |
| 5 | 강아지의 행동 | Friendly, gentle, playful, and active. |
| 6 | 고양이의 특성 | Black-and-white fur, bright eyes, and curious. |
| 7 | 필요한 돌봄 | Food, water, playtime, a clean bed, and love. |
| 8 | Essential Question 답 | Friendly, gentle, healthy, and loved. |
| 9 | 마무리 | What is your perfect pet like? |

## 슬라이드 조작

- `→` 또는 `Space`: 다음 슬라이드
- `←`: 이전 슬라이드
- `1`~`9`: 해당 슬라이드로 이동
- `Home` / `End`: 첫 장 / 마지막 장

## 사진 처리와 개인정보

- 사진은 사용자가 직접 제공한 가족 사진입니다.
- 발표용 사본은 최대 1,400px로 축소하고 EXIF 등 메타데이터를 제거했습니다.
- 개인 사진이므로 저장소를 공개하거나 GitHub Pages에 배포하기 전에 공개 범위를 반드시 확인하세요.

## 사용 팁

1. `script.html`에서 영어 문장과 동작을 함께 연습합니다.
2. `cards.html`을 브라우저에서 열고 인쇄해 큐 카드로 사용합니다.
3. 발표 당일 `index.html`을 전체 화면으로 열고 방향키로 넘깁니다.
4. 슬라이드 8의 `friendly · gentle · healthy · loved` 네 단어는 반드시 또렷하게 말합니다.
